约翰内斯·特里特米乌斯

原理与机制

人物：约翰内斯·特里特米乌斯（Johannes Trithemius）。留存文献的句子是：「The first printed book on cryptography, Polygraphia, written in 1508 by the German monk Trithemius and published in 1518, contains the first tableau」。该表被描述为「a square table on 24 characters listing all shift substitutions for a fixed ordering of plaintext alphabet characters」，并按行依次使用。

为什么重要

把可用的移位替换全部写进一张方形表，第一次让多表使用有了可复制的书面对象：使用者依据行列关系操作。

应用与实例

该人物的登记信息用于定位其在多表替换中的角色与产出；引用时只写来源支持的机构、文本、标准或机器，不把后人归功写成本人事实。

边界与攻击面

如果行的顺序是固定的，攻击者只需还原顺序而不必猜测密钥；同一段注记接着记 1553 年 Belaso「suggested using an easily changed key (and key-phrases as memory aids) to define the fixed alphabetic (shift) substitutions」——后来被拿来作文章的正是可换的行选择，而非表本身。

历史与背景

1508 年写作与 1518 年出版在留存文献里是两个分开的年份，不可合并；同一段落前承阿尔贝蒂、后接 1563 年的 Porta 著作。

可核角色与证据链

约翰内斯·特里特米乌斯归入多表替换，登记时代为文艺复兴与宗教改革。该条目只登记有来源支持的教育/任职机构、公开文本或专利、参与的标准/机器/事件与可核同行评价。来源账本包括：Wikipedia search entry for 约翰内斯·特里特米乌斯；MacTutor History of Mathematics Archive, University of St Andrews。
