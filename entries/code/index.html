原理与机制

术语：编码（表）（Code）。RFC 4949 "Internet Security Glossary, Version 2" 给 code 四个定义。第一个是「A system of symbols used to represent information, which might originally have some other representation.Examples: ASCII, BER, country code, Morse code」；第二个带 /cryptography/ 领域标签，正文为「An encryption algorithm based on substitution; i.e., a system for providing data confidentiality by using arbitrary groups (called "code groups") of letters, numbers, or symbols to represent units of plain text of varying length」；第三个说明同类替换算法「used to shorten messages rather than to conceal their content」。

为什么重要

第二个定义与 code book 条目相互指认：code book 的两条定义分别是「Document containing a systematically arranged list of plaintext units and their ciphertext equivalents.[C4009]」与「An encryption algorithm that uses a word substitution technique.[C4009] (See: code, ECB.)」，而 code 第二定义末尾留下「(See: codebook, cryptography.)」形成回指。替换单元是「varying length」的明文单位，这解释了为什么编码表与逐字符替换的密码在结构上不同。

应用与实例

第一个定义把编码当作表示系统，例如 ASCII、Morse code、国家码；第四个定义则是编程义项「To write computer software」。同一词条的弃用缩写说明提醒不要把 Message Authentication Code 之类的术语缩写成 code，即该词在安全文献中承担多重义项、需要按上下文区分。

边界与攻击面

RFC 4949 的弃用用法说明用 SHOULD NOT 建议 IDOC 不要把 code 当作 cipher、hash 这类表示密码算法的词，或 cipher text、以及 encrypt、hash 这类施加密码算法的动词的同义词（该段原文见 rfc4949.txt 的 code 词条）。HAC §1.4 把加密方案与 cipher 绑定（「An encryption scheme is sometimes referred to as a cipher」），§1.5.2 则写道「Substitution ciphers are block ciphers which replace symbols (or groups of symbols) by other symbols or groups of symbols」；HAC 第 1 章并未把 code 与 cipher 作为一对概念加以区分。

历史与背景

RFC 4949 于 2007 年 8 月发布为 FYI 36、类别 Informational，头部署名 R.Shirey，文末 Author’s Address 写明 Dr.Robert W.Shirey，头部另有 Obsoletes: 2828。词条末尾的方括号代号指向 §7 Informative References 清单：[C4009] 对应美国国家安全系统委员会的 National Information Assurance (IA) Glossary，即「CNSS Instruction No.4009, revised June 2006」，code book 的两条定义都带这一标记。RFC Editor Note 同时提醒「The recommendations and some particular interpretations in definitions are those of the author, not an official IETF position.」该条目保留表示义、密码义、压缩义与编程义四个层次，可见这一术语的历史用法仍留在现行词典里。
