冷启动攻击

本文和目录元数据已通过本轮复核。

原理与机制为什么重要应用与实例边界与攻击面历史与背景逐步示例与核验参考出处

原理与机制

攻击：冷启动攻击（Cold Boot Attack）。冷启动攻击利用 DRAM 的剩余记忆：攻击者在系统断电后迅速重启（或把内存芯片转移到另一台机器），再对内存成像并恢复其中的密钥。论文用这种方法攻破了 BitLocker、TrueCrypt 和 FileVault 等磁盘加密系统。

为什么重要

DRAM 断电后内容不会立即消失，而是逐渐衰减：常温下通常先保持数秒，之后快速衰减，低温下可保持数分钟甚至数小时。论文还发现衰减的时序和终态往往可预测，因此可以用纠错算法重建密钥。按“输入 → 状态 → 变换 → 输出 → 判据”复述机制；每一步都要能指出谁执行、改变什么、留下什么证据。无法指出证据的步骤，只能标为待核，不能写成已复现。

应用与实例

论文从内存镜像中恢复磁盘加密系统的密钥，也恢复了 Mac OS X 的登录口令和 Apache 服务器的 RSA 私钥。作者指出，任何在攻击者获得物理访问时仍留在内存中的敏感数据都可能受影响。

边界与攻击面

冷启动攻击需要物理接触，不是远程攻击；防御包括在失去物理控制前清除或隐藏密钥、限制从网络或可移动介质启动、保护 DRAM 芯片以及让内存更快衰减。论文认为这些措施只能部分缓解风险，没有简单办法能彻底消除。### 形式模型

术语小词典

冷启动攻击
利用断电后 DRAM 残留数据恢复密钥。
DRAM
常温下断电后短时间内仍保留内容的动态随机存取存储器。
剩余记忆
断电后内存数据逐渐衰减但仍可读取的现象。
全盘加密
对存储设备整体加密，挂载期间密钥通常留在内存中。
内存加密
对内存内容加密；只有在复位或断电时销毁密钥，才可能阻止冷启动恢复。
侧信道
利用物理实现的泄漏而非数学弱点。
