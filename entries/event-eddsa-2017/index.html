Ed25519 进入 RFC

本文和目录元数据已通过本轮复核。

原理与机制为什么重要应用与实例边界与攻击面历史与背景逐步示例与核验参考出处

原理与机制

事件：Ed25519 进入 RFC（Ed25519 Published in RFC 8032）。RFC 8032 摘要写明：「This document describes elliptic curve signature scheme Edwards-curve Digital Signature Algorithm (EdDSA).The algorithm is instantiated with recommended parameters for the edwards25519 and edwards448 curves」。§4 末句写明「This document specifies parameters resulting in the HashEdDSA variants Ed25519ph and Ed448ph and the PureEdDSA variants Ed25519 and Ed448」。

为什么重要

强度取向写在 §1：「Ed25519 is intended to operate at around the 128-bit security level and Ed448 at around the 224-bit security level.A sufficiently large quantum computer would be able to break both.」§8.5 给出选型建议：Ed25519「is widely implemented and has many high-quality implementations」，因此「if a high 128-bit security level is enough, use of Ed25519 is RECOMMENDED; otherwise, Ed448 is RECOMMENDED」。

应用与实例

该文件由 IRTF 的 Crypto Forum Research Group 形成共识并以 Informational 类别发布，标题页题名为「Edwards-Curve Digital Signature Algorithm (EdDSA)」，页眉记为「RFC 8032 EdDSA: Ed25519 and Ed448 January 2017」；状态说明写明「Documents approved for publication by the IRSG are not a candidate for any level of Internet Standard」，即它提供的是研究组推荐的参数而非标准轨道规范。

边界与攻击面

文档中的强制要求是技术性的而非部署性的：§5.1 规定「The context (if present at all) MUST be empty」，§8.7 要求「the receiver MUST buffer the entire message」；并且 §1 明确足够大的量子计算机可破解两者。该条目不使用强制部署、已取代 DSA等该文件未陈述的表述。

历史与背景

RFC 8032 于 2017 年 1 月发布；摘要另说明「An example implementation and test vectors are provided」，即同时给出示例实现与测试向量；§4 末句把 Ed25519/Ed448 及其 Pure 与 Hash 变体一并写入规范。

术语小词典

EdDSA
爱德华曲线上的确定性签名方案族。
Ed25519
约 128 位强度的 PureEdDSA 变体。
Ed448
约 224 位强度的变体。
HashEdDSA
先对消息做预哈希的变体（Ed25519ph/Ed448ph）。
PureEdDSA
直接对消息签名的变体。
context
签名上下文字段，最长 255 字节；纯 Ed25519 要求为空，Ed25519ctx 则建议非空。
