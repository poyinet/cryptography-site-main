GRAIN Stream Cipher

Article review and catalog-metadata acceptance are recorded separately. The library remains under construction.

Principles

Algorithm: GRAIN (GRAIN 流密码). ### A hardware stream cipher with an 80-bit key and 64-bit IV

GRAIN loads an 80-bit key K into an 80-bit nonlinear feedback shift register (NFSR) B, and a 64-bit IV plus a 16-bit all-ones constant into an 80-bit linear feedback shift register (LFSR) S. The LFSR recurrence guarantees a long period; the quadratic and cubic terms of the NFSR supply nonlinearity; an output filter mixes taps from both registers into one keystream bit. ### 160 initialization clocks

After loading, the cipher runs 160 blank clocks. Each clock still updates B and S, but the output bit is XORed back into both feedback inputs, so every key and IV bit diffuses through the 160-bit state. Only then does output begin:

z_t = ⊕{i∈A} b{t+i} ⊕ h(s_{t+3}, s_{t+25}, s_{t+46}, s_{t+64}, b_{t+63}), A={1,2,4,10,31,43,56}. ### Family and standards

Grain-128 extends the key/IV to 128/96 bits and uses 256 initialization clocks; Grain-128a adds optional authentication and enters the ISO/IEC 29167-13 RFID crypto suite; Grain-128AEAD v2 reached the final of the NIST lightweight cryptography competition as the only stream cipher in that round.

Why it matters

GRAIN targets gate count, power and memory, not software throughput. One 80-bit LFSR, one 80-bit NFSR and a combinational filter produce the keystream without AES S-boxes or large lookup tables. The simplest implementation emits one bit per clock; unrolling to 16 bits per clock trades area for speed.

That makes it suitable for RFID tags, wireless sensors and extremely tight embedded secure boot. Grain v1 is in the eSTREAM hardware portfolio and Grain-128a is standardized in ISO/IEC 29167-13, so its role is a dedicated stream cipher for constrained environments, not general server encryption.

Applications

Grain-128A provides authentication and encryption between RFID tags and interrogators over ISO/IEC 18000 air interfaces, with authentication as an optional service. Grain-128AEAD targets lightweight IoT links that need confidentiality and integrity together.

Grain v1 appears mostly in hardware crypto cores, sensor nodes and cryptographic teaching and analysis. It can also serve as a pseudorandom bit generator, but encryption use requires XOR with plaintext and strict IV discipline.

Limits & attacks

GRAIN is a synchronous stream cipher: reusing the same key and IV reproduces the same keystream, and the XOR of two ciphertexts reveals the XOR of the plaintexts. Grain v1 has no built-in authentication. Grain-128a authentication is an optional protocol capability; a deployment must actually enable and verify the tag, or an attacker can alter ciphertext undetected.

Initialization depth is part of the security boundary. Grain v1 uses 160 clocks and Grain-128 uses 256 to achieve diffusion; cutting initialization to a few dozen clocks exposes cube attacks, guess-and-determine attacks and near-collision analysis. Published results mostly target reduced rounds or weakened initialization, but that is not permission to reduce the round count.

Bit-serial hardware also leaks power and electromagnetic information. A physical adversary requires masking, dual-rail logic or constant-power design. Algorithmic security and implementation security are separate acceptance criteria.

History

Hell, Johansson and Meier submitted Grain to eSTREAM in 2005, and Grain v1 entered the hardware portfolio. Grain-128 moved to a 128-bit key in 2006; Grain-128a added optional authentication in 2011 and later became the ISO/IEC 29167-13 RFID crypto suite. Grain-128AEAD v2 reached the final of the NIST lightweight cryptography process as the only stream cipher in the last round.
