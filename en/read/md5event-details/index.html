Glossary

2004 MD5 collision event
the MD5 collision result published in ePrint 2004/199 in 2004.
MD5
a hash function with a 128-bit digest and 512-bit blocks.
Collision
two different messages with the same digest.
Collision pair
two concrete messages and their common digest.
ePrint 2004/199
the Wang-Feng-Lai-Yu paper on MD4, MD5, HAVAL-128 and RIPEMD collisions.
EUROCRYPT 2005
the Wang-Yu conference paper detailing the MD5 attack technique.
Differential path
the path specifying how message differences propagate.
Message modification
adjusting message words before the search to satisfy differential conditions.
128-bit digest
MD5's output length; a generic birthday attack costs about 2^64.
Birthday bound
for a 128-bit digest, the generic birthday attack costs about 2^64.
Collision resistance
the difficulty of finding two messages with the same digest.
Preimage resistance
the difficulty of finding any message for a given digest.
Second-preimage resistance
the difficulty of finding another message with the same digest as a given message.
Digital signature
a private-key signature over a message digest; a collision breaks the unique message-signature binding.
Certificate
a CA signature binding a public key to an identity; an MD5 collision breaks that binding.
HMAC-MD5
HMAC instantiated with MD5; RFC 6151 discusses its continued use.
RFC 6151
the 2011 RFC updating MD5 and HMAC-MD5 security considerations.
RFC 1321
the 1992 MD5 specification.
Concrete colliding messages
two downloadable collision inputs that can be independently verified.
Common digest
the MD5 value shared by two colliding messages.
Collision attack
a method for finding same-digest message pairs.
Message block
MD5's 512-bit (64-byte) processing unit; the two example messages are 128 bytes each, two blocks.
Complexity estimate
a theoretical estimate of required operations, not a measured runtime.
Event timeline
MD5 in 1992, ePrint in 2004, EUROCRYPT in 2005, RFC 6151 in 2011.
