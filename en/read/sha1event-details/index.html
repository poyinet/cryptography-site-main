Glossary

2005 SHA-1 collision event
the 2005 announcement of a collision attack on full SHA-1, not the publication of a concrete collision instance.
SHA-1
a 160-bit, 80-round hash function; the 2005 attack targets the full 80-round version.
Collision
two different messages with the same digest.
Collision attack
a method for finding same-digest message pairs; the 2005 result is an attack method and complexity estimate.
Birthday bound
for a 160-bit digest, a generic birthday attack costs about 2^80.
53-round attack
the early-2005 theoretical attack on SHA-1 reduced to 53 rounds.
Full 80 rounds
the complete SHA-1 round count; the 2005 paper reports a collision attack with about 2^69 operations.
2^69
the 2005 paper's complexity estimate for a full-SHA-1 collision attack.
Complexity estimate
a theoretical estimate of required operations, not a measured runtime or cost.
Differential path
the path specifying how message differences propagate in a differential attack.
Message modification
adjusting message words before the search so differential conditions hold.
Reduced rounds
a SHA-1 version with fewer rounds for analysis; results do not automatically apply to the full algorithm.
SHAttered
the first actual full-SHA-1 collision instance, produced by Stevens et al. in 2017; not the 2005 event.
Actual collision instance
two concrete messages and their common digest that can be independently verified.
Chosen-prefix collision
a collision where the attacker chooses a different prefix for each message.
Shambles
the 2020 SHA-1 chosen-prefix collision work by Leurent and Peyrin.
PGP identity impersonation
using colliding certificates to transfer a third party's certification signature from one key to a forged key.
NIST deprecation
NIST restricting or ending certain SHA-1 uses because of cryptanalytic weaknesses.
SP 800-131A
NIST's algorithm-transition guidance; Table 8 gives SHA-1 status for signature generation, verification and non-signature applications.
RFC 6194
the 2011 RFC summarizing SHA-0/SHA-1 security considerations.
CPU-year/GPU-year
units of compute time used to describe collision-search cost, not strict energy or price.
SHA-1 compression
one invocation of the SHA-1 compression function per 512-bit block.
Certificate signature
a CA's signature over certificate content; a hash collision can break its unique binding.
Timeline
the ordering of the 2005 attack, 2011 guidance, 2017 SHAttered and 2020 Shambles.
