Length Extension Attack

The text and catalog metadata passed current review.

Principles

Attack: Length Extension Attack (长度扩展攻击). ### Merkle–Damgård state

A Merkle–Damgård hash splits the message into blocks and iterates a compression function f over a chaining value: h_i=f(h_{i−1},m_i). The final digest is the last chaining value; padding pad=0x80||0…||len encodes the message length in the final block. ### Length-extension forgery

Given H(K||m) and the length of K, an attacker treats the digest as a chaining value and continues compressing m′, obtaining H(K||m||pad||m′) without knowing K. If a protocol uses MAC=H(K||m) and compares digests, the attacker can append any message and forge a valid MAC. ### HMAC and sponge constructions

HMAC uses H((K⊕opad)||H((K⊕ipad)||m)); the outer hash hides the inner chaining value and blocks extension. A SHA-3 sponge output is not a reusable chaining value, so it is also unaffected.

Why it matters

This is the classic “hash as MAC” mistake: H(K||m) looks like a keyed hash but exposes the internal state to the attacker.

It explains why HMAC is not redundant and why protocols must distinguish hash, MAC, KDF and signature primitives.

Applications

Given MAC=H(K||m) and its digest, an attacker guesses the length of K, computes the padding, treats the digest as an IV and continues compressing m′ to obtain H(K||m||pad||m′); sending the new message with the new digest passes verification. The old Flickr API, custom tokens and “key-prefix” file-integrity schemes exhibited the flaw.

Modern practice uses HMAC, KMAC, BLAKE3 keyed mode or AEAD; if a hash-based MAC is unavoidable, use HMAC or length-encode and domain-separate first.

Limits & attacks

Affected: MD5, SHA-1 and Merkle–Damgård SHA-256/512; unaffected: SHA-3/SHAKE, BLAKE2/3, HMAC and KMAC. Truncated SHA-384/512-256 outputs also cannot be extended directly.

History

Merkle and Damgård independently introduced the MD construction in 1989; RFC 2104 standardized HMAC in 1997 to fix key-prefix MACs; NIST SP 800-107r1 regulates HMAC usage; SHA-3’s sponge changed the state-output model.

It became a required counterexample in protocol-design courses and pushed MAC primitives toward standardization.
