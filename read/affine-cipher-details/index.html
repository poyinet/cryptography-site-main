仿射密码

本篇详解的复核与目录元数据验收分别记录；全库仍在逐项建设。

原理与机制为什么重要应用与实例边界与攻击面历史与背景逐步示例与核验参考出处

原理与机制

术语：仿射密码（Affine Cipher）。定义句在 HAC 第七章的 Example 7.49：「The affine cipher on a 26-letter alphabet is defined by eK(x) = ax + b mod 26」。该例接下来的取值范围句丢了不等号字形，因此该条目只引可读的这一截，并按同例转述：密钥是 (a, b) 这一对，解密形如 dK(c) = (c - b)a-1 mod 26（式中的 a-1 即 a 的模逆，留存件的上标层级已丢失）。

为什么重要

为什么它是移位密码的一般化：同一例给出的结论句是「Shift ciphers are a subclass defined by a = 1.」——把乘数固定为 1 就退回凯撒式移位。同例还给出可逆的充要条件，留存件印作 gcd(a, 26) = 1，也就是说并非所有 (a, b) 都是合法密钥；仿射在此的实质内容就是这条乘数必须与模互质的限制。

应用与实例

用法层次是教学与历史，不是部署：该章在把古典材料交给 7.3 节时明说这些古典密码与技术是出于历史与教学理由而呈现的（原文同段还称它们既不精巧也不安全、通常不适合实际使用——该句带着丢失的节号字形，故只转述不整段引用）。因此该条目不写任何现代用途，也不把它说成现代运算原语的历史来源，那种说法不在留存件里。

边界与攻击面

限度在密钥规模：同节先说移位密码只有 s = |A| 个密钥可穷举、因而可被轻易破解，紧接着把同一判断给了仿射密码——「A similar comment holds for affine ciphers (Example 7.49).」。也就是说，乘数与位移的组合（还要受互质条件约束）仍在穷举范围之内；该节没有在这里印出仿射密码的密钥空间数值，该条目因此只按同例的条件式转述，不给具体个数。

历史与背景

版本事实：留存件首行说明它是《Handbook of Applied Cryptography》（Menezes、van Oorschot、Vanstone，CRC Press, 1996）的一章，章页标题为 Block Ciphers，而章内页脚印 1997 的版权行。Example 7.49 的标题把这个例子标为历史性质；除此之外，留存文本不给仿射密码的提出者、年代或起源叙述（同章对其它古典构造才有带年份的注记，如 Hill 密码），该条目也不替它补。

定义检查模型

上位概念 → 区别特征 → 正例 → 反例 → 易混边界。正例必须落在外延内；反例必须刚好跨过边界；同义词不能代替定义。

术语小词典

仿射密码
以 e(x) = ax + b（模 26）定义的替换密码（HAC Example 7.49）。
key (a, b)
仿射密码的密钥即乘数与位移这一对。
gcd(a, 26) = 1
该例给出的可逆充要条件。
shift cipher
a = 1 时的特例子类。
trivially broken
同节对移位与仿射两例给出的判断（密钥太少，可穷举）。
exhaustive search
穷举整个密钥空间的攻击；这里密钥太少，穷举即可破解。
