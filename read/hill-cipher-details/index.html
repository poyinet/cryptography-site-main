希尔密码

本篇详解的复核与目录元数据验收分别记录；全库仍在逐项建设。

原理与机制为什么重要应用与实例边界与攻击面历史与背景逐步示例与核验参考出处

原理与机制

术语：希尔密码（Hill Cipher）。例 7.52 的定义句给出密钥与运算对象：用一个可逆的 n×n 方阵，「as the key to map an n-character plaintext」到一个同长的密文块，其逐分量形式是矩阵与列向量的乘积按字母表大小取模；解密用同一个方阵的逆。字母被先映成整数（书中以 A–Z 对 0–25 为例），因此整套体制就是模意义下的线性代数。

为什么重要

为什么要一次处理一整块：这一例直陈它的数学形态——「is a linear transformation」。把 n 个字母混进同一个输出块，单字母频率就不再逐位对应，这正是它相对单表替换的改进点；代价在下面那条限度里兑现。

应用与实例

可用之处在书中是结构性的：块长 n 决定所需运算量与密钥规模，方阵必须可逆否则解密不存在；§7.8 的注记补了一条实现层面的观察——Hill 本人注意到取一个自逆映射（对合）作加密映射时，同一函数可兼作解密。该例在书中被标为历史条目，因此该条目不写现代部署。

边界与攻击面

限度由定义直接推出：既然加密是线性变换，密钥就满足一组线性同余方程，书中因此写明该体制「falls under known-plaintext attack」；§7.8 注记对同一方阵密码作同样评价，说它是一条易受已知明文攻击的线性变换。块的混合换来的是对已知明文的脆弱，两句出自同一数学形态。

历史与背景

断代与来历写在 §7.8 注记里：「The matrix cipher of Example 7.52 was proposed in 1929 by Hill」，并称它给出了多字母组替换的可行方法；同一注记还把它与可逆方阵、对合解密等观察连在一起。该条目据此把时代落在 1929 所属的战间期，命名则沿用文中以提出者称呼该方阵密码的写法。

术语小词典

希尔密码
以一个可逆方阵为密钥、把 n 个字符一次线性变换的古典密码。
n-gram（n 元组）
希尔密码一次处理的字符块。
invertible matrix（可逆方阵）
能用于解密的方阵密钥。
polygraphic substitution（多字母组替换）
一次替换多个字母的类别。
linear transformation（线性变换）
希尔密码的数学形态。
known-plaintext attack（已知明文攻击）
该书指出的失效路径。
